-------LINKED LIST-------
A LINKED LIST s a linear data structure where elements (Called nodes) are 
connected using references (pointers).
Each node has: Data (the value it stores)
Next(a reference to the next node)

linked list don't store elements in contiguous memory. They're flexible for 
insertion and deletion but slower for random access.
